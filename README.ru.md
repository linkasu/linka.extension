# Формат LINKa Extension (.linka)

> 🇬🇧 English version: [README.md](README.md)

## Назначение
`.linka` — это ZIP-архивы с карточочными наборами для комплекса LINKa.look. В каждом файле лежит описание набора (`config.json`) и мультимедийные материалы, которые используют карточки. Этот репозиторий фиксирует стандарт, чтобы внешние редакторы могли уверенно создавать и проверять LINKa-наборы.

## Структура контейнера
- Файл — обычный ZIP. `config.json` лежит в корне рядом со всеми ресурсами; вложенных каталогов нет.
- Каждый медиафайл хранится один раз. Если несколько карточек делят картинку или звук, редактор создает дополнительную копию с префиксом `_`, чтобы сохранить уникальность имён, и обновляет ссылки в JSON.
- Пути в `config.json` содержат только имена файлов. При открытии набора приложение распаковывает архив во временную папку и ищет ресурсы по этим именам.

```
primer.linka
├── config.json
├── yabloko.png
├── yabloko.ogg
└── space.png
```

## Схема `config.json`
Файл — UTF-8 JSON со следующими полями верхнего уровня:

| Поле | Тип | Обязательно | Описание |
| --- | --- | --- | --- |
| `version` | строка | да | Текстовая метка версии. Текущий редактор пишет `"1.3"`, но загрузчик принимает ранние значения, если структура совпадает. |
| `description` | строка | нет | Произвольное описание, отображаемое в диалоге LINKa.look. |
| `directSet` | bool | нет (по умолчанию `false`) | Прячет строку вывода и заставляет приложение воспроизводить звук сразу при выборе карточки. |
| `columns` | целое | да | Число колонок на странице (>=1). |
| `rows` | целое | да | Число строк на странице (>=1). |
| `withoutSpace` | bool | да | При `true` подписи карточек склеиваются без пробелов, а аудиокнопки в редакторе скрываются. |
| `cards` | массив | да | Список карточек в порядке обхода строка-за-строкой; этот порядок управляет пагинацией. |

### Карточки
Поля отдельной карточки:

| Поле | Тип | Обязательно | Описание |
| --- | --- | --- | --- |
| `id` | целое | да | Устойчивый идентификатор; редактор сохраняет исходные номера. |
| `width` | целое | нет (по умолчанию `1`) | Зарезервировано под карточки, занимающие несколько ячеек; значения <1 приводятся к 1. |
| `height` | целое | нет (по умолчанию `1`) | Аналогично `width`. |
| `imagePath` | строка | обязательно для `Common`/`Space` | Имя изображения (PNG/JPG/GIF). GIF остаются анимированными при проигрывании. |
| `title` | строка | обязательно для `Common`/`Space` | Подпись под картинкой и текст, который попадает в строку вывода (кроме `Space`). |
| `audioPath` | строка | опционально | Имя файла `.ogg`, `.mp3` или `.wav`. Для речевых наборов (`withoutSpace = false`) редактор настойчиво предлагает добавить озвучку. |
| `cardType` | enum (целое) | да | `0` = `Common`, `1` = `Space`, `2` = `Fake`. |

### Типы карточек
- `Common (0)` — обычная карточка с подписью, картинкой и (желательно) аудио. При выборе текст добавляется в строку и/или звучит.
- `Space (1)` — символ пробела. Редактор автоматически подставляет знак ␣, генерирует картинку и блокирует ручное редактирование. В пользовательском режиме такая карточка вставляет пробел даже при `withoutSpace = false`.
- `Fake (2)` — пустая «заглушка» для выравнивания сетки и принудительного переноса карточек на следующую страницу. Все медиаполя должны оставаться пустыми.

## Логические флаги
- **`withoutSpace`** — определяет способ набора текста. При `true` приложение добавляет подписи подряд, удаляет символы по одному и озвучивает накопленную строку целиком. В редакторе для таких наборов скрываются элементы загрузки аудио.
- **`directSet`** — предназначен для «прямых» наборов, которые должны озвучиваться моментально. Включение флага прячет строку вывода и принудительно активирует режим «воспроизводить звук с карточек» вне зависимости от пользовательских настроек.

## Сетка и страницы
Карточки читаются в том порядке, в котором перечислены в массиве `cards`. Приложение разбивает список на страницы по `rows × columns` элементов, заполняет строки слева направо и автоматически добавляет страницы по мере необходимости. Незаполненные ячейки последней страницы остаются пустыми, если только вы не добавили `Fake`-карточки для закрепления макета.

## Ресурсы
- Изображения: поддерживаются PNG, JPG и GIF (анимация сохраняется). Лучше использовать квадратные холсты, чтобы избежать пустых полей.
- Аудио: предпочтителен OGG, но загружаются и MP3/WAV с последующей конвертацией при сохранении.
- Имена файлов должны быть уникальными и по возможности ASCII-дружественными — редактор всё равно удаляет пути, но при совпадениях добавляет подчёркивания.

## Пример `config.json`
```json
{
  "version": "1.3",
  "description": "Пример продуктового набора",
  "directSet": false,
  "columns": 5,
  "rows": 3,
  "withoutSpace": false,
  "cards": [
    {
      "id": 0,
      "imagePath": "yabloko.png",
      "title": "Яблоко",
      "audioPath": "yabloko.ogg",
      "cardType": 0
    },
    {
      "id": 1,
      "imagePath": "space.png",
      "title": "\u2423",
      "audioPath": "",
      "cardType": 1
    }
  ]
}
```

## Чек-лист валидации
1. Убедитесь, что файл открывается как ZIP, а `config.json` лежит в корне.
2. Проверьте структуру `config.json` и наличие всех упомянутых ресурсов.
3. Удалите неиспользуемые медиа, чтобы не раздувать архив.
4. Протестируйте набор в LINKa.look: пагинация, произнесение и флаги `directSet`/`withoutSpace` должны вести себя как задумано.
